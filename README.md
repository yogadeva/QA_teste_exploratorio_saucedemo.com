# Swag Labs — QA Exploratório Manual

Projeto de prática de QA no site de treino SauceDemo (produto Swag Labs),
usado para aplicar técnicas de teste de forma estruturada, simulando o
ambiente de um time real.

## Objetivo
Praticar análise de teste e documentação de bugs, aplicando
as técnicas do syllabus ISTQB CTFL (particionamento de equivalência,
valor de limite, teste exploratório) a um produto real.

## Ferramentas e tecnologias
- Jira (gestão de casos de teste e bugs, estrutura Épico → Tarefa)

## O que foi testado
- Fluxo de login (usuários válidos e com problemas propositais)
- Carrinho de compras e contador de itens
- Checkout: validação de campos, cálculo de totais, navegação
- Ordenação e consistência de imagens na listagem de produtos

## Estrutura do repositório

/evidencias → prints e vídeos dos bugs encontrados
/casos-de-teste → casos documentados em formato de texto
